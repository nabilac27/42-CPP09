
>> extracts and converts data from a stream.

.eof() checks whether the stream has reached the end of its input.

The >> operator reads characters from ss, converts them to a double, and stores the result in value.

"123.45"         ->    123.45
stringstream     ->    double

Text is parsed and converted into a numeric value.

There are two important concepts here:
    1. >> extracts and converts data from a stream.
    2. .eof() checks whether the stream has reached the end of its input.



std::stringstream ss("123abc");
double value;

ss >> value;


Here, >> successfully extracts 123 and stops at a.
So:
- value becomes 123.
- "abc" remains unread.
- The extraction is considered successful.
This is why checking >> alone isn't enough.

.eof() means end of file, but it also works with stringstream.
It returns true when the stream's end-of-file state has been set, usually because a read reached the end of the available input.

std::stringstream ss("123abc");
double value;

ss >> value;

std::cout << value << std::endl;    // 123
std::cout << ss.eof() << std::endl; // 0 (false)

std::list is an STL container that stores elements in a doubly linked list.
Unlike std::vector, its elements are not stored next to each other in memory.

std::list is a doubly linked list. 
Each element is stored in a separate node containing the value and pointers to the previous and next nodes. 
Unlike vector, its elements are not contiguous in memory. I use it in RPN as a LIFO stack with push_back(), back(), and pop_back().
