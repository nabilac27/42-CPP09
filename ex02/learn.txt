| Step              | What happens                                   |
| ----------------- | ---------------------------------------------- |
| **1. Parse**      | Read `argv[]`                                  |
| **2. Validate**   | Positive integer? Invalid character? Overflow? |
| **3. Store**      | Put numbers into your two containers           |
| **4. Before**     | Print original sequence                        |
| **5. Sort**       | Ford-Johnson on container 1                    |
| **6. Sort again** | Ford-Johnson on container 2                    |
| **7. After**      | Print sorted sequence                          |
| **8. Timing**     | Print time for each container                  |
